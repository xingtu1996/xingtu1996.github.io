# 小包乐园维护约定

- 面向两到三岁儿童，保留大触控区和一步到位的反馈。音效和广播以点按触发。背景音乐默认关闭，可单独启用。
- 保持无登录、广告、内购、追踪、麦克风权限和家庭身份数据。旅程和亲属称谓属于虚构的游戏场景。
- 将可发布的播放器、素材、Service Worker 和清单放在本目录内。声音文件和缓存清单一起提交。每次修改缓存资源时更新版本标识。
- 外部录音入库前核对原作、作者与许可。更新《录音来源》，说明裁剪、转码和其他改动，保留相同方式共享素材的衍生音频许可。
- 发布前检查方块、弹珠清盘、鸣笛、开关门、家人接送、背景音乐和广播互斥。区分 WebKit、Chromium 模拟与手机真机结果。测试证据使用日志。
