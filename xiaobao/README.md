# 小宝乐园

面向两到三岁孩子的静态网页游戏，包含动物方块、弹珠消除、开高铁与车站广播。

- [正式游戏](https://xingtu1996.github.io/xiaobao/)
- [直接打开车站广播](https://xingtu1996.github.io/xiaobao/#radio)
- [录音来源与许可](./sound-sources.html)
- [游戏规格](./SPEC.md)
- [维护约定](./AGENTS.md)

生产镜像位于 GitHub Pages 仓库的 `xiaobao/`。把整个目录交给静态 HTTP 服务器，打开 `index.html` 即可试玩。通过 HTTPS 发布后，首次打开并看到「可离线游玩」即可用同一浏览器离线重开。音频由用户点按启动。
